# Android SDLC & Release Management Pipeline

## Overview
This repository documents the end-to-end Software Development Lifecycle (SDLC) and release management for multiple native Android applications. It demonstrates hands-on experience with mobile architecture, deployment pipelines, application testing, and the Google Play Console ecosystem.

## Application Portfolio

### 1. Branching Realms (Production Release)
* **Status:** Live on the Google Play Store.
* **Live Application:** [View Branching Realms on Google Play](https://play.google.com/store/apps/details?id=com.digitalbard.branchingrealms)
* **Technical Focus:** Full-stack mobile deployment. Managed production Keystore signing, strict Google Play policy compliance, and executed a live, public production release.
* *Note: The database architecture and Python automation pipelines for this application are detailed separately in the `Branching-Realms-Backend` repository.*

### 2. Scratchboard Art Studio (Closed Testing)
* **Status:** Actively in Google Play Closed Testing tracks.
* **Technical Focus:** Native mobile digital drawing application focusing on UI component testing, precise canvas rendering, and touch-input tracking mechanics. Navigated the Google Play closed testing requirements to initiate user validation.

### 3. Homophones (Closed Testing Sprint)
* **Status:** Actively in Google Play Closed Testing tracks.
* **Technical Focus:** Executed an accelerated 16-hour rapid development and deployment sprint. Took the application from initial concept, through functional UI and state design, directly into a compiled, signed, and deployed closed testing release.

## Core Technologies & Release Tools
* **Development Environment:** Android SDK, Kotlin, Godot Engine
* **Release Engineering:** Google Play Console, Keystore Management, Closed/Open Testing Tracks, App Bundle (AAB) & APK Compilation, UI/UX Validation
